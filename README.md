# Principal Gradient Selection for Efficient Multi-Task Learning with Many Tasks

This repository contains implementations of gradient weighing methods (**PCGrad**, **CAGrad**, and **Linear Scalarization**) both with and without the **Principal Gradient Selection (PGS)** algorithm. 

This codebase is a modified extension of the methods presented in **FAMO** ([Paper](https://arxiv.org/pdf/2306.03792.pdf) | [GitHub](https://github.com/Cranial-XIX/FAMO)).
